# Locarion

> A modern multi-tenant SaaS platform for car rental agencies.

## Overview

Locarion is a portfolio-grade SaaS application built to demonstrate modern software engineering practices through the development of a real-world car rental management platform.

The project focuses on:

- Multi-tenant SaaS architecture
- Laravel 12 REST API
- React + TypeScript frontend
- PostgreSQL
- Docker
- GitHub Actions (CI/CD)
- Clean Architecture
- DevOps best practices

## Current Status

The project is currently in the engineering design phase before implementation begins.
